# Batched DC operating points: CPU vs CUDA

Generated by `rustspice bench-batch` @ e3a9a0e. Circuit: the 32-diode cascade of b6 (MNA dimension 34, 423 workspace words per corner).

- CPU: 13th Gen Intel(R) Core(TM) i9-13900HX (32 rayon threads)
- GPU: NVIDIA GeForce RTX 4090 Laptop GPU (CUDA driver 13.4); initialisation in this process (driver, context, PTX JIT): 298 ms
- Times are end to end, median of 7 repetitions (3 above 100k corners): from the `BatchCircuitInput` list to one solution vector per corner, including plan building, parameter mapping, transfers and CPU re-solves.
- CPU batch API: `Simulator::run_batch_dc_op` (rayon, one topology clone and one full CPU solve per corner). cpu_ref: the batch kernel's CPU build (rayon). CUDA: the same kernel source compiled to PTX by cuda-oxide, one corner per thread, FP64.
- Differences are `max |a - b| / (1 + max(|a|, |b|))` over all corners and unknowns. Every corner the kernel does not converge is re-solved by the CPU solver (counted in the last column).
